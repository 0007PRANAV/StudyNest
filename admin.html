🔒 Account security

Passwords are hashed by Supabase Auth and can never be viewed from this dashboard — not even by an administrator. That is what keeps users safe if the database is ever exposed.

To reset a password or resend a confirmation email, open Supabase → Authentication → Users. You can also enable email/SMTP so users can reset it themselves from the app.

🔒 Why can't I see passwords?

StudyNest never stores plain-text passwords. When a user signs up, Supabase Auth hashes the password with bcrypt and keeps only the hash. The original password cannot be recovered by anyone, including admins.

If someone forgets their password, reset it in Supabase → Authentication → Users, or let them use “Forgot password” in the app once email is configured.
